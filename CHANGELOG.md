## [0.2.0] - 2026-11-14

### Features

- **repo:** pnpm + Turborepo monorepo scaffold — `apps/*` and `packages/*`
  workspaces, shared `tsconfig.base.json`, a single pinned toolchain
  (`pnpm@9.15.5`, Node >= 20) and `@edcalderon/versioning` for version and
  changelog management across all four packages
- **core:** `@pingus/core` deterministic trait engine, generation state machine
  and palette. Produces output that is bit-identical to the reference generator
  in `08-tech/scripts/generate.mjs` for the full 2,369-pingu collection, with a
  parity test suite guarding the invariant. `08-tech/config/*.json` remains the
  single source of truth; `scripts/sync-config.mjs --check` detects drift
  against the mirrored TypeScript config
- **pingu-render:** `@pingus/pingu-render` procedural SVG renderer — draws any
  pingu at any calor directly from its traits. Isomorphic and fully
  deterministic, with no image assets to ship or pin
- **contracts:** `@pingus/contracts` ERC-721 implementation with no owner mint,
  immutable thresholds, immutable breeding windows, a zero breed fee and
  ERC-2981 royalties. Mutable per-token state is packed into a single storage
  slot; 30 Hardhat tests cover the mint and breeding rules, batch attestation
  gas budget, EIP-712 encuentro consent and the owner's complete power set
- **web:** `@pingus/web` Vite + React landing page and mint app, consuming the
  core engine and the renderer directly from source. Builds to a static SPA and
  runs in demo mode until `VITE_CONTRACT_ADDRESS` and `VITE_CHAIN_ID` are set
