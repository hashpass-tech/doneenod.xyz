# Voice & Copy

## Rules

1. **Spanish-first.** English is the translation, not the original.
2. **Lowercase.** Always. Including the start of sentences.
3. **No exclamation points.** Ever.
4. **Short.** If it needs a second sentence, cut the first.
5. **Never explain the mechanic emotionally.** State it. Let it land.
6. **No crypto vocabulary.** No gm, wagmi, ser, fam, wen, LFG, ape, diamond
   hands, floor, utility, ecosystem, roadmap.
7. **Never hype.** The deadpan pingu is the brand. Match its tone.

---

## The four words

Everything reduces to these. On garments, on the mint page, in metadata:

```
NACE        born      GEN 0
CALIENTA    warms     GEN 1
HACE        does      GEN 2
HECHO       done      GEN 3
```

## Core lines

### The collection

```
2.369 pingus. todos congelados.
ninguno está terminado.
```


### On thawing

```
el hielo no se derrite solo.
```

```
nadie derrite tu cubo por ti.
```

```
el calor viene de hacer. no de tener.
```

### On the gate

```
no compras la chaqueta. te la derrites.
```

> *You don't buy the jacket. You thaw into it.*

### On transfer

```
puedes comprar un pingu terminado.
no puedes comprar haberlo terminado.
```

> The most important line in the project.

### On breeding

```
el encuentro no cuesta nada. nosotros no cobramos.
```

> *We charge nothing.* Not "it's free" — on Ethereum mainnet the network
> charges gas, and saying "free" then showing a gas estimate at signing is the
> kind of small dishonesty this project cannot afford. The partner genuinely
> pays nothing: their consent is an off-chain signature.

```
hacer no se hereda.
tu trabajo derritió tu cubo. tu hijo empieza en el suyo.
```

### On the end

```
el vapor no se reproduce.
el vapor terminó.
```

```
no hay generación 4.
```

### On the absence of utility

Say it out loud. Owning the absence is stronger than faking a roadmap.

```
no hay token.
no hay staking.
no hay roadmap.
hay 2.369 cubos y lo que hagas con el tuyo.
```
